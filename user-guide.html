1. Обзор

scan-git-push — утилита для анализа коммитов GitHub-репозитория за указанный период. Использует LLM (Ollama или GitHub Models API) для генерации саммари каждого коммита.

ХарактеристикаОписание
ЯзыкPython 3.11+
LLM провайдерыOllamaGitHub Models API
Форматы выводаКонсольMarkdownHTML
Анализируемый период1–365 дней (настраивается)

2. Предусловия

Обязательно Python 3.11+

Скачать: python.org/downloads

Обязательно Файл секретов d:\projects\fullstack-demo\.secrets

Формат файла:

GITHUB_TOKEN=ghp_ваш_токен_github
GITHUB_MODELS_TOKEN=ghp_ваш_токен_github

Оба токена могут быть одинаковыми (используйте GitHub Personal Access Token с правом repo).

Обязательно Хотя бы один LLM-провайдер:
  • Ollama — запущена локально на http://localhost:11434 с установленной моделью
  • GitHub Models API — доступен бесплатный тариф (требуется токен GitHub)
Опционально Git — не обязателен, утилита работает через GitHub API

3. Установка

1 Клонировать репозиторий и перейти в каталог:

cd D:\projects\scan-git-push

2 Создать виртуальное окружение:

python -m venv .venv

3 Активировать окружение:

# Windows:
.venv\Scripts\activate

# Linux/macOS:
source .venv/bin/activate

4 Установить зависимости:

pip install -e ".[dev]"

4. Конфигурация

Отредактируйте файл config.json:

{
  "GIT_PROJECT": "https://github.com/AlexOstrov/fullstack-demo.git",
  "GIT_DAY": 7,
  "SECRETS_PATH": "d:\\projects\\fullstack-demo\\.secrets",
  "LLM_PROVIDER": "ollama",
  "OLLAMA_BASE_URL": "http://localhost:11434",
  "OLLAMA_MODEL": "llama3.1:8b",
  "GH_MODELS_MODEL": "gpt-4o-mini",
  "GH_MODELS_ENDPOINT": "https://models.github.ai/inference"
}
ПараметрОписаниеЗначение по умолчанию
GIT_PROJECTURL GitHub-репозитория—
GIT_DAYКоличество дней для анализа (1–365)7
SECRETS_PATHПуть к файлу с токенамиd:\projects\fullstack-demo\.secrets
LLM_PROVIDERollama или github_modelsollama
OLLAMA_MODELМодель Ollama для анализаllama3.1:8b
GH_MODELS_MODELМодель GitHub Models APIgpt-4o-mini

5. Запуск

Базовый запуск

python -m scan_git_push

С указанием пути к конфигу

python -m scan_git_push --config C:\path\to\config.json

Процесс работы

  1. Утилита загружает конфигурацию и проверяет секреты
  2. Проверяет доступность выбранного LLM-провайдера
  3. Получает список доступных моделей
  4. Запрашивает у пользователя выбор модели (нумерованный список)
  5. Получает коммиты из репозитория за указанный период
  6. Анализирует каждый коммит через LLM с прогресс-баром
  7. Генерирует отчёты в консоль, Markdown и HTML
Интерактивный выбор модели

При запуске утилита покажет нумерованный список доступных моделей. Введите номер модели и нажмите Enter.

6. Результаты

Консоль

Формированный вывод с прогресс-баром, списком файлов и саммари каждого коммита.

Markdown-отчёт

Сохраняется в reports/{repo}_{date}.md — структурированный отчёт со всеми коммитами.

Интерактивный HTML-отчёт

Сохраняется в reports/{repo}_{date}.html — автономный файл (не требует интернета) с:

  • Навигацией по коммитам (боковая панель)
  • Статистикой (коммиты, файлы, LLM chunks)
  • Саммари каждого коммита

7. Решение проблем

Ошибка Причина Решение
Exit code: 1
Secrets file not found		 Файл .secrets отсутствует по указанному пути Создайте файл d:\projects\fullstack-demo\.secrets с токенами
Exit code: 2
GITHUB_TOKEN not found / empty		 Токен отсутствует или пуст в файле секретов Проверьте формат: GITHUB_TOKEN=ghp_...
Exit code: 3
Ollama NOT available		 Ollama не запущен или недоступен Запустите Ollama: ollama serve. Проверьте URL в конфиге
Exit code: 4
GitHub Models API NOT available		 Неверный токен или нет доступа к API Проверьте GITHUB_MODELS_TOKEN в файле секретов
Exit code: 5
Repository not found		 Репозиторий не существует или нет доступа Проверьте URL в GIT_PROJECT, убедитесь в правах доступа
BadCredentialsException: 401 Недействительный GitHub токен Создайте новый токен на github.com/settings/tokens
Модель не найдена в Ollama Указанная модель не установлена Установите: ollama pull llama3.1:8b
No commits found В указанный период нет коммитов Увеличьте GIT_DAY или проверьте репозиторий
Медленный анализ Большой репозиторий или медленная модель Уменьшите GIT_DAY, используйте меньшую модель Ollama
Важно: GitHub API Rate Limits

Без аутентификации GitHub ограничивает запросы до 60/час. С токеном — 5000/час. Утилита использует retry с backoff, но при частом запуске лимиты могут исчерпываться.

Проверка доступности Ollama

# Проверить, что Ollama запущена:
curl http://localhost:11434/api/tags

# Список установленных моделей:
ollama list

# Установить модель (если нужно):
ollama pull llama3.1:8b

Пример файла секретов

GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
GITHUB_MODELS_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Безопасность

Файл .secrets добавлен в .gitignore и не коммитится в репозиторий.
