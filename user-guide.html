1. Обзор

scan-git-push — утилита для анализа коммитов GitHub-репозитория за указанный период. Использует LLM (Ollama, Mistral AI или GitHub Models) для генерации саммари каждого коммита.

ХарактеристикаОписание
ЯзыкPython 3.11+
LLM провайдерыOllamaMistral AIGroq / GitHub Models (недоступны в РФ)
Форматы выводаКонсольMarkdownHTML
Анализируемый период1–365 дней (настраивается)

2. Предусловия

Обязательно Python 3.11+

Скачать: python.org/downloads

Обязательно Файл секретов d:\projects\fullstack-demo\.secrets

Формат файла:

GITHUB_TOKEN=ghp_ваш_токен_github
MISTRAL_API_KEY=ключ_из_console.mistral.ai

GITHUB_TOKEN нужен для чтения репозитория. MISTRAL_API_KEY — для Mistral AI (получите на console.mistral.ai).

Обязательно Хотя бы один LLM-провайдер:
  • Mistral AI — онлайн, OpenAI-совместимый API, есть бесплатный тариф (требуется MISTRAL_API_KEY)
  • Ollama — запущена локально на http://localhost:11434 с установленной моделью
  • Groq / GitHub Models — заблокированы в РФ (Groq: 403 Forbidden, GitHub Models: закрыт 30.07.2026)
Опционально Git — не обязателен, утилита работает через GitHub API

3. Установка

1 Клонировать репозиторий и перейти в каталог:

cd D:\projects\scan-git-push

2 Создать виртуальное окружение:

python -m venv .venv

3 Активировать окружение:

# Windows:
.venv\Scripts\activate

# Linux/macOS:
source .venv/bin/activate

4 Установить зависимости:

pip install -e ".[dev]"

4. Конфигурация

Отредактируйте файл config.json:

{
  "GIT_PROJECT": "https://github.com/AlexOstrov/fullstack-demo.git",
  "GIT_DAY": 7,
  "SECRETS_PATH": "d:\\projects\\fullstack-demo\\.secrets",
  "LLM_PROVIDER": "mistral",
  "OLLAMA_BASE_URL": "http://localhost:11434",
  "OLLAMA_MODEL": "llama3.1:8b",
  "GH_MODELS_MODEL": "gpt-4o-mini",
  "GH_MODELS_ENDPOINT": "https://models.github.ai/inference",
  "GROQ_MODEL": "llama-3.3-70b-versatile",
  "GROQ_ENDPOINT": "https://api.groq.com/openai/v1",
  "MISTRAL_MODEL": "mistral-small-latest",
  "MISTRAL_ENDPOINT": "https://api.mistral.ai/v1",
  "DB_PATH": "db/",
  "DB_RETENTION_DAYS": 60
}
Переключение провайдера на лету

Значение LLM_PROVIDER задаёт требования к токену и модель по умолчанию, но при запуске утилита опрашивает оба провайдера и показывает модели из всех доступных. Вы можете выбрать любую модель из списка, независимо от LLM_PROVIDER.

Настройка Mistral AI (онлайн-модель)

  1. Зарегистрируйтесь на console.mistral.ai и создайте API-ключ в разделе API Keys
  2. Добавьте ключ в .secrets: MISTRAL_API_KEY=...
  3. Установите LLM_PROVIDER в mistral (или оставьте ollama и выберите модель Mistral в меню)
  4. Запустите утилиту и выберите модель из списка [Mistral]
Лимиты бесплатного тарифа Mistral AI

Бесплатный тариф Mistral AI имеет ограничения на количество запросов в минуту/день. При исчерпании лимита запросы возвращают ошибку — дождитесь сброса или выберите модель Ollama. Требуется интернет-соединение.

5. Запуск

Базовый запуск

python -m scan_git_push
 или Запуск: .venv\Scripts\python.exe -m scan_git_push

С указанием пути к конфигу

python -m scan_git_push --config C:\path\to\config.json

Процесс работы

  1. Утилита загружает конфигурацию и проверяет секреты
  2. Опрашивает Ollama и Mistral AI API (best-effort)
  3. Собирает список моделей от всех доступных провайдеров
  4. Запрашивает у пользователя выбор модели (нумерованный список — можно переключиться между провайдерами на лету)
  5. Получает коммиты из репозитория за указанный период
  6. Анализирует каждый коммит через LLM с прогресс-баром
  7. Генерирует отчёты в консоль, Markdown и HTML
Интерактивный выбор модели

При запуске утилита покажет нумерованный список доступных моделей. Введите номер модели и нажмите Enter.

Дедупликация коммитов (база данных)

При каждом запуске утилита проверяет уже проанализированные коммиты в SQLite-базе (db/). Коммиты, которые были проанализированы ранее, не анализируются повторно — это предотвращает дублирование при ежедневных запусках. Записи старше DB_RETENTION_DAYS (по умолчанию 60 дней) автоматически удаляются из базы.

6. Результаты

Консоль

Формированный вывод с прогресс-баром, списком файлов и саммари каждого коммита.

Markdown-отчёт

Сохраняется в reports/{repo}_{date}.md — структурированный отчёт со всеми коммитами.

Интерактивный HTML-отчёт

Сохраняется в reports/{repo}_{date}.html — автономный файл (не требует интернета) с:

  • Навигацией по коммитам (боковая панель)
  • Статистикой (коммиты, файлы, LLM chunks)
  • Саммари каждого коммита

Важно: GitHub API Rate Limits

Без аутентификации GitHub ограничивает запросы до 60/час. С токеном — 5000/час. Утилита использует retry с backoff, но при частом запуске лимиты могут исчерпываться.
